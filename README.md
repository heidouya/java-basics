# 🚀 Java 入门指南
欢迎来到 Java 入门指南 项目！🎯
本项目专为 Java 初学者设计，旨在通过简单易懂的示例和讲解，帮助你快速掌握 Java 编程的基础知识。

## 📚 项目简介
这是一个面向零基础或刚接触 Java 的学习者的开源项目。内容涵盖 Java 基础语法、面向对象编程、常用工具类、异常处理、集合框架等核心知识点。每个知识点都配有代码示例和注释，方便你边学边练。

## 🧭 内容导航
- 📘 基础语法：变量、数据类型、运算符、流程控制（if/else、循环）
- 🧱 面向对象：类与对象、封装、继承、多态、抽象类、接口
- 🧰 常用类：String、Arrays、Scanner、Math 等
- 🧪 异常处理：try-catch、throws、自定义异常
- 📦 集合框架：List、Set、Map 的使用与区别
- 📁 文件操作：File、IO 流基础
- 🛠️ 工具类与实战：日期处理、正则表达式、简单项目练习

## 🤝 如何贡献
如果你在学习过程中发现错误，或者有更好的示例想分享，欢迎提交 Issue 或 Pull Request！
让我们一起帮助更多人入门 Java。

## 📖 推荐学习路线
1. 先学 basics 包中的基础语法
2. 掌握 oop 包中的面向对象思想
3. 学习 utils 和 exceptions 等常用工具
4. 深入 collections 和 io 操作
5. 尝试完成 projects 中的小项目
