# 🚀 Java 入门指南
欢迎来到 Java 入门指南 项目！🎯

本项目专为 Java 初学者设计，旨在通过简单易懂的示例和讲解，帮助您快速掌握 Java 编程的基础知识。

## 📚 项目简介
这是一个面向零基础或刚接触 Java 的学习者的开源项目。内容涵盖 Java 基础语法、面向对象编程、常用工具类、异常处理、集合框架等核心知识点。每个知识点都配有 [相关视频](https://v.douyin.com/N2dnFtOiJwU/)、示例代码，方便您边学边练。

## 🧭 内容导航
- 📘 基础语法：变量、数据类型、运算符、流程控制（if/else、循环）
- 🧱 面向对象：类与对象、封装、继承、多态、抽象类、接口
- 🧰 常用类：String、Arrays、Scanner、Math 等
- 🧪 异常处理：try-catch、throws、自定义异常
- 📦 集合框架：List、Set、Map 的使用与区别
- 📁 文件操作：File、IO 流基础
- 🛠️ 工具类与实战：日期处理、正则表达式、简单项目练习

## 📌 环境要求
- JDK 21 或更高版本
- 任意 Java 开发工具（IDEA / Eclipse / VSCode 等）

## 🚀 如何使用
克隆项目到本地：
```bash
git clone https://github.com/heidouya/java-basics
```
1. 导入 IDE（推荐 IntelliJ IDEA 或 Eclipse）
2. 按顺序学习：从 day01 模块开始，逐步深入
3. 动手实践：每个示例都建议自己敲一遍，尝试修改和扩展

## 📖 推荐学习路线
1. 先学习基础语法，掌握变量、数据类型、流程控制等
2. 理解面向对象编程思想：类、对象、封装、继承、多态
3. 学习常用工具类和异常处理
4. 深入集合框架和文件操作
5. 尝试完成一些小项目来巩固所学知识
